# 视频剪辑：统一测试说明

## 入口与操作

项目 → 剪辑台 → 最终成片。

1. 选择已生成的 Scene 视频，或上传/插入项目视频素材。
2. 设置入点、出点，或把播放器停在需要的位置后点击“播放头处分割”。
3. 用上移、下移或拖动上方片段条调整顺序；“排除”仅移出本次编排。
4. 设置速度、音量和画面/原声淡入淡出。
5. 在前一个片段设置出站转场：硬切、交叉溶解、向左擦除、向右滑动。最后一个片段必须硬切。转场占用两段重叠时间，因此输出时长会减少。
6. 按需设置亮度、对比度、饱和度、片段标题、图片或视频叠加。叠加使用当前项目的素材，位置是0～1的归一化比例；宽度是画幅比例。
7. 可缩放时间轴支持拖动左右边缘裁剪、8px吸附（Alt临时取消）、点击刻度定位播放头。转场重叠已计入位置；重叠区快速预览选择前一个源片段，并非转场的最终渲染。撤销/重做最多保留80步，仅当前集当前页面会话内有效；时间轴获得焦点时可用Ctrl/⌘ Z、Shift Z。
8. “保存剪辑草稿”仍保存到当前浏览器；另有“保存到服务端/读取服务端草稿”，按项目/集持久化到SQLite，可跨设备读取。恢复需确认；服务端使用revision防止覆盖其他窗口修改，冲突返回409，必须读取并审核最新草稿后再保存。草稿不是媒体备份，素材仍需可访问；保存不会创建生成/合并任务。预览时长仅为元数据，正式导出仍校验真实媒体。
9. 点击“渲染完整预览”或顶部合并按钮，使用同一条正式渲染流程。完成后在成片历史播放、下载；失败可以按原快照重试。

## 第二阶段：画面变换与关键帧

展开每段的“画面变换 / 裁切 / 关键帧”：

- 四边裁切是源画面的比例；左右、上下分别至少保留5%。
- 完整显示 `contain` / 居中填满 `cover`。成片画幅继续沿用现有首段源视频尺寸，不改变原素材，也不新增全局画幅设置。
- 缩放0.25–4，X/Y位移为成片画幅宽高的-1–1倍，旋转-360–360度。
- 处理顺序：裁切 → 适配画幅 → 围绕画幅中心旋转（超出画幅部分裁掉）→ 缩放/位移 → 现有调色/淡化/叠加/标题。空白使用黑底。
- 关键帧时间为裁剪、变速后的片段本地秒数，不是原视频/整集时间；最多32帧，递增且间隔至少1毫秒。缩放、位置、旋转线性插值；两端保持端点值。裁切和适配不参与动画。
- 在预览时间设置静态参数后，点击“添加/更新关键帧”。有动画时静态参数不会自动改写关键帧；清空动画才恢复静态参数。
- 分割会采样切点并给右片段重新从0计时，保持曲线连续。缩短时长导致关键帧越界时明确拒绝保存/导出，不静默重配动画；应先编辑/清除关键帧。
- 本地草稿、服务端草稿、撤销重做和合并快照都保留变换；正式导出重新校验真实时长。
- 变换面板里的播放器提供几何预览（无声，不含转场/叠加/字幕/最终色彩）；页面原有快速播放器仍显示原视频。最终效果必须以FFmpeg完整渲染为准。

自动验证包含真实FFmpeg动画、画幅/时长不变、像素采样证明位移生效、原始文件哈希不变，以及关键帧分割、越界和JSON回传。

## 第三阶段：多轨与声音

- 最终成片每段可展开“多轨 / 波形 / 音量包络 / 打点”。主视频仍由原来的编排序列驱动；每段额外支持最多8条项目图片/视频叠加轨；另有独立的“跨片段图片 / 视频轨”，以成片秒数为坐标，不依赖Scene或主视频切点。
- 叠加轨按列表从底到顶合成，可单独设置开始/结束、本素材起点、位置、宽度、透明度和隐藏。所有时间为剪辑变速后的片段本地秒数。短视频默认循环；起点按素材时长取模。图片忽略源起点。叠加轨无声音，声音需独立AudioLayer。
- 既有单层画中画保留，新增轨在其上方叠加。每轨参与来源归属、安全路径及快照校验。草稿/撤销重做/导出持久化轨道参数；源素材改变时拒绝旧快照重试。
- 按需点击“读取真实波形”，由浏览器解码真实媒体音轨的各声道峰值，限制32MB，不伪造波形；格式不支持或无音轨会显示错误。波形为原始音轨，非处理后混音/ASR/节拍检测。点击波形可定位本片段源时间。声音工作区独立音频层也提供波形。
- 片段原声支持最多64个线性音量包络点（0–4倍），与片段基础音量相乘；新增点位于片段播放头。对白/BGM/环境声/音效仍使用原来的独立音频层，不由主视频包络控制。
- 声音工作区编辑AudioLayer时可设置独立包络，时间从该层开始后0秒计。保存到SQLite，进入合并快照；剪辑裁切/变速/重排映射会采样边界、重定位并缩放其包络。淡入淡出、ducking仍另外相乘。
- 每段最多100个人工标记，显示为总时间轴菱形，可点击/吸附。标记只供剪辑参考，不导出可见文字、不修改Scene/Dialogue。分割会分配并重定位标记及轨道，保持音量曲线连续。裁短导致范围越界时明确拒绝，不静默删轨。
- 包络预览用浏览器音量（上限100%，未混独立层）；最终增益、淡化和多轨画面以完整FFmpeg渲染为准。响度自动校准、自动节拍识别尚未实现。

### 跨片段自由叠加轨

- 在最终成片主时间轴下选择项目图片/视频，点击“播放头插入叠加素材”。最多8层，允许跨越多个Scene及主视频转场。
- 拖动整个条目改变成片入点（不改变素材起点），两端手柄独立裁剪；左裁剪同步推进素材起点。8px吸附到主片段切点、其他叠加边缘及播放头；Alt临时关闭吸附。
- 用字段设置入出点、素材起点、位置、宽度、透明度或隐藏；上下层按钮决定覆盖次序。叠加素材不自动加入声音，不改变原片段及其顺序。
- 全局轨道在主视频concat/xfade之后合成，跨切点不重启；Dialogue字幕及功能文字在全局轨上方。即时播放器仍不模拟这些合成画面，使用完整渲染检查结果。
- 本地/SQLite草稿、统一撤销重做均同时保存主视频序列与全局轨；服务端使用同一个revision CAS。旧客户端省略轨道时保留已有轨道，显式[]才清空。恢复时缺失素材或缩短后的越界轨道会报错，不静默丢弃。
- 全局轨道采用不可变合并快照v8，保存源项目素材路径/类型/大小及有序轨道参数；重试重新验证，旧v6/v7无轨道工程兼容。正式导出按真实裁剪、变速和转场后的总时长再次验证，轨道不可越界。
- 这是单条主故事序列 + 自由叠加层的编辑模型，不包含多主轨磁性联动或跨工程嵌套；独立声音层仍在声音工作区编辑。

测试包括跨转场全局轨道连续显示及文字层顺序、全局草稿CAS/回滚、轨道参数与源变更拒绝、拖动裁剪/吸附、统一历史，以及多层覆盖/显示时段像素采样、原声音量RMS变化、素材SHA不变、来源归属、快照失效、独立层包络保存/清除及裁切变速映射。

## 第四阶段：基础视觉包装

- 每段展开“视觉包装 / 标题动画 / 风格模板”。标题仍在原来的标题输入框编辑，包装不改写标题原文、Dialogue、Scene或素材。标题使用现有ASS/libass及已审核的Noto Sans SC，不采用未知系统字体。
- 标题支持无动画、淡入淡出、短距离滑入和逐字高亮（复用ASS karaoke，不是逐字文字解码或语音对齐）。白色字幕、金色题名、银色名牌复用现有ScreenText样式；独立Dialogue字幕开关和功能文字配置不变。片段标题依旧独立渲染。
- 原创参数模板：清晰字幕、暖色金色题名、冷色银色名牌、黑白逐字标题。覆盖已有包装前确认；仅替换本片段风格/标题样式和动画，保留故事、标题文字、时长、转场、轨道。
- 原创暖/冷色逐通道RGB LUT直接用FFmpeg lutrgb计算，无外部文件；柔和/黑白为eq/hue程序滤镜。不提供第三方影片风格模仿或未经审核.cube导入。外部3D LUT的许可证登记、哈希核验与管理界面仍待后续，不伪称已完成。
- 转场增加颗粒溶解、经黑/经白淡变、四方向擦除/滑动、圆形展开/收拢。仍限0.05–2秒，且不超过相邻片段各自时长的一半；最后一段必须硬切。音频同步使用原有跨淡化，不改源时长。
- 片段内及跨Scene全局叠加轨支持矩形（保持源透明度）、椭圆、圆角矩形蒙版。蒙版与原始alpha相乘，透明PNG不会被强制填实；透明度再相乘。不含自由曲线、跟踪、羽化或人物抠像。旧单层画中画保持不变。
- 色彩只作用于主片段，不改变独立叠加素材；蒙版只作用于所选叠加轨。参数进入草稿、撤销重做及合并快照。分割保留包装/蒙版，但标题动画会在新片段重新开始。
- 快速浏览器预览尚不模拟包装、蒙版或转场，最终效果必须“渲染完整预览”。自动测试使用真实FFmpeg验证蒙版像素、暖冷色差和全部新增转场；ASS测试验证动画标记。

## 预览与导出边界

- 快速预览播放原视频，应用播放速度、近似调色和音量；浏览器音量最多100%，导出可放大至400%。CSS调色不是FFmpeg最终颜色的精确模拟。
- 转场、叠加、标题、独立配音、BGM及字幕需要渲染后查看；“渲染完整预览”不是无成本即时预览，会生成成片任务及历史。
- 前后约一帧是按24fps估算的播放器定位，不是源视频帧精确解码工具。
- 标题导出依赖已安装并审核的 `noto-sans-sc` 字体。缺失时提交前明确报错；不会偷偷换字体。
- 视频叠加只取画面，不额外混入叠加视频的声音；底片原声、独立配音和音频层仍由现有混音选项控制。
- 修改的是剪辑参数，不改原始视频、Scene、故事、生成提示词或已采用候选。不调用GPU生成节点。

## 建议统一验收顺序

1. 两段各4秒视频：第一段2倍速，第二段正常速度，转场0.5秒，期望总长约5.5秒。
2. 将一段裁为0.5～3.5秒，再在2秒处分割，交换两段；核对画面顺序和原声对应。
3. 混入无声片段：其他片段原声必须保留，无声区间应为静音。
4. 设置淡入淡出和片段音量，核对不会因分割在新切点重复淡化。
5. 加标题，分别测试顶部/底部、不同字号、中文、引号与大括号。
6. 添加图片叠加，再改为短视频叠加；检查位置、尺寸、透明度和循环，原素材不被修改。
7. 添加对白、功能文字和音频层后，裁切、变速、重排及重复同一 Scene；检查它们随实际片段时间重映射。
8. 保存草稿、刷新、显式恢复；确认编排和参数恢复；删除素材后恢复不能伪造可用素材。
9. 失败任务按快照重试；原输入/叠加素材/编排已变化时，应拒绝静默替换输入。

## 已有自动验证

- Go全量回归与构建、前端测试与生产构建。
- 真实本地FFmpeg：变速、三种转场、混合硬切、音频交叉淡化、静音片段、图片叠加、ASS标题。
- 实际 `runAudioMerge` 任务：混合尺寸、变速、转场、叠加，任务完成并验证时长、音轨及原文件SHA-256不变。
- 时间映射及快照回归：对白、音频层、屏幕文字、重复片段、变速与转场重叠。

这些检查不代表已验证所有生产素材、远程SSH部署或完整人工交互体验。统一测试时仍需核对实际工程输出。
