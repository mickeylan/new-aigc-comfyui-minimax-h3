## 项目概述

ComfyStudio 是一个基于 ComfyUI 的企业级 AI 视频生成管理平台，专注于 **MiniMax H3** 多模态视频生成模型的管理和调度。

**核心能力：**
- 多卡 GPU 调度（8×NVIDIA L40）
- MiniMax H3 工作流（文生视频、图生视频、首尾帧、参考视频）
- AI 漫剧工作台（剧本→分镜→视频→成片全链路）
- 角色/道具资产一致性管理
- TTS 配音与字幕生成

### 核心服务

#### 1. Service (handlers.go) - 服务聚合层

```go
type Service struct {
    Cfg       *config.Config
    DB        *gorm.DB
    Mgr       *InstanceManager    // 实例管理
    Mon       *GPUMonitor        // GPU 监控
    Tasks     *TaskService       // 任务调度
    Hub       *Hub               // WebSocket Hub
    Upload    *UploadManager      // 文件上传
    Remote    *RemoteExec        // SSH 执行
    Volc      *VolcClient       // 火山引擎
    Projects  *ProjectService    // 漫剧项目
    Materials *MaterialService   // 素材库
}
```

**职责：**
- 聚合所有子服务
- 提供 HTTP Handler 入口
- 启动后台服务（GPU 监控、任务恢复、项目流水线）

#### 2. TaskService (task_service.go) - 任务调度核心

```go
type TaskService struct {
    cfg         *config.Config
    db          *gorm.DB
    manager     *InstanceManager
    gpuMon      *GPUMonitor
    hub         *Hub
    remote      *RemoteExec
    mu          sync.Mutex
    scheduleMu  sync.Mutex        // 选卡原子锁
    executing   map[string]bool  // task_id -> 执行中
    wsActive    map[string]chan struct{}  // task_id -> stop
    nodeClasses map[string]map[string]float64  // 节点权重缓存
}
```

**核心流程：**

```
CreateTask() → Execute() → [PickInstance → ReserveInstance] 
    → RenderWorkflow() → SubmitPrompt() → ListenWS() → finishTask()
```

**关键方法：**
| 方法 | 作用 |
|------|------|
| `CreateTask()` | 创建任务，校验素材，存入 DB |
| `Execute()` | 调度并提交任务（异步） |
| `RenderWorkflow()` | 模板占位符替换、素材路径转换 |
| `pickInstance()` | 并发探测 8 实例，选择最优 |
| `reserveInstance()` | 原子选卡 + GPU 预占 |
| `listenWS()` | WebSocket 监听进度 |
| `handleWSEvent()` | 处理 ComfyUI 事件 |
| `finishTask()` | 查询 history 提取结果 |
| `StartRecovery()` | 后台恢复卡死任务 |

#### 3. ComfyClient (comfy_client.go) - ComfyUI HTTP 客户端

```go
type ComfyClient struct {
    Host string
    Port int
    HTTP *http.Client
}
```

| 方法 | ComfyUI 端点 | 说明 |
|------|-------------|------|
| `Ping()` | `GET /system_stats` | 心跳检测 |
| `GetLoad()` | `GET /queue` + `/system_stats` | 队列+显存 |
| `SubmitPrompt()` | `POST /prompt` | 提交工作流 |
| `Interrupt()` | `POST /interrupt` | 中断执行 |
| `DeletePrompt()` | `POST /queue` | 删除任务 |
| `GetHistory()` | `GET /history/{id}` | 查询结果 |

#### 4. ComfyWSClient (ws_client.go) - WebSocket 客户端

```go
type ComfyWSClient struct {
    host     string
    port     int
    clientID string
    onEvent  func(type_ string, data map[string]any)
    done     chan struct{}
}
```

**事件类型 (ComfyUI 0.30+):**

| 事件 | 处理 |
|------|------|
| `execution_start` | status → running |
| `executing` | 更新 current_node |
| `progress_state` | 按节点权重计算进度 |
| `execution_success` | finishTask() 提取结果 |
| `execution_error` | 记录错误 |
| `execution_interrupted` | status → cancelled |

#### 5. Hub (ws_client.go) - 前端推送中心

```go
type Hub struct {
    mu      sync.Mutex
    clients map[*websocket.Conn]struct{}
}
```

**方法：**
- `Register(conn)` - 客户端连接
- `Unregister(conn)` - 客户端断开
- `Send(conn, type_, payload)` - 推送给单个连接
- `Broadcast(type_, payload)` - 广播到所有连接

#### 6. VolcClient (volc_engine.go) - 火山引擎客户端

```go
type VolcClient struct {
    db    *gorm.DB
    httpc *http.Client
}
```

| 方法 | 用途 |
|------|------|
| `Chat()` | 文生文（剧本/创作方案） |
| `GenerateImage()` | 文生图（分镜画面/角色标准像） |
| `Speech()` | TTS 配音 |

#### 7. ProjectService (project_service.go) - 漫剧项目

```go
type ProjectService struct {
    cfg           *config.Config
    db            *gorm.DB
    volc          *VolcClient
    tasks         *TaskService
    remote        *RemoteExec
    upload        *UploadManager
    hub           *Hub
    imageSem      chan struct{}  // 文生图并发限制(3)
    assetInflight map[uint]bool // 资产生成去重
}
```

**流水线阶段：**
```
plan → script → images → videos → merge → finished
```

**关键流程：**
1. **创作方案生成**：`HandleGeneratePlan()` → 调用 volc.Chat() 生成剧名/三幕/角色/反派/节奏
2. **剧本生成**：`HandleGenerateScript()` → volc.Chat() 生成剧本 → 拆分场景
3. **画面生成**：`HandleGenerateAllImages()` → volc.GenerateImage()，信号量限流 3 并发
4. **视频生成**：`HandleGenerateAllVideos()` → TaskService.Execute() → ComfyUI i2v
5. **视频合并**：`HandleCreateMerge()` → ffmpeg concat + 音轨

#### 8. InstanceManager (instance_manager.go) - 实例管理

```go
type InstanceManager struct {
    cfg    *config.Config
    db     *gorm.DB
    remote *RemoteExec
}
```

**调度模式：**
| 模式 | 说明 |
|------|------|
| `ssh` | SSH 裸进程管理（默认） |
| `docker` | docker compose 容器管理 |
| `local` | 本机开发模式 |

**关键方法：**
- `Start(gpu)` - 启动单实例
- `Stop(gpu)` - 停止单实例
- `Restart(gpu)` - 重启单实例
- `comfyHostOf(port)` - 返回可达主机

#### 9. GPUMonitor (gpu_monitor.go) - GPU 监控

```go
type GPUMonitor struct {
    cfg    *config.Config
    remote *RemoteExec
    mu     sync.RWMutex
    status map[int]GPUStatus
}
```

**采集内容：**
- GPU 利用率、温度、功耗
- 显存使用/总量
- 进程列表（PID/名称/显存占用）
- 宿主 CPU/内存

**采集间隔：** 默认 3 秒（`config.yaml` 可配置）

```json

  "data": {

    "status": "running",
    "progress": 45.5,
    "current_node": "KSampler",
```

#### 推送类型

| type | 触发时机 | data |
|------|---------|------|

| `instance_update` | 实例状态变化 | instance 对象 |
| `gpu_update` | GPU 状态变化 | gpu 列表 |

### WebSocket 连接

```javascript
// 在 App.vue 或 router 守卫中建立连接

function connectWS() {
  const ws = new WebSocket(wsUrl())
  
  ws.onopen = () => {
    store.setConnected(true)
  }
  
  ws.onmessage = (e) => {
    const msg = JSON.parse(e.data)
    
    switch (msg.type) {
      case 'snapshot':
        store.setSnapshot(msg.data)
        break
      case 'task_update':
        // 更新任务列表
        break
      case 'instance_update':
        // 更新实例状态
        break
      case 'gpu_update':
        store.gpus = msg.data
        break
    }
  }
  
  ws.onclose = () => {
    store.setConnected(false)
    // 重连
    setTimeout(connectWS, 3000)
  }
}
```
