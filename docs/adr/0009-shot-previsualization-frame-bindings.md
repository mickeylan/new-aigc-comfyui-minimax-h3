# ADR-0009：Shot选帧绑定与可审阅分镜提示词

状态：已按用户授权实现并完成本地回归，用户已授权提交及推送；未部署。

## 决策

- 独立追加 ShotPrevisFrame 表，不升级预演v1/v2/v3，不向Shot自由文本字段塞几何JSON。每次显式绑定创建不可变历史记录，引用同一Project/Scene内已有Shot ID；不新建或重写镜头。
- 绑定必须基于已保存且未过期的预演revision。服务端从该文档按整数毫秒采样冻结对象位置/朝向、机位、天气、GLB内容哈希与片段参数，并保留原文档与采样时间用于骨骼复现。GLB本体仍仅存在浏览器，缺失时拒绝导出而非静默占位。
- 保存Scene正文版本、Shot内容指纹、预演revision和快照哈希；预演/Scene/Shot删除、重排或变更使旧绑定显式过期，但历史仍可查看。绑定是派生层，不替代Scene、Shot与对白权威。
- 新路径：选帧→确认绑定已有Shot→准备Scene分镜图提示词草稿（明确以该Shot为画面目标、以帧空间为建议）→编辑审阅→确认替换Scene.image_prompt。不是修改Shot剧情，也不是自动提交生成。不得把该Shot构图无区别应用于其它Shot。
- 提示词预览来源覆盖当前Scene/Shot/对白/项目/参考图和绑定ID/快照/预演版本；采用时再次校验并以事务保护，过期返回409。独立记录采用提示词摘要；不冒用原Scene站位“已应用”标志。
- 原基础站位→提示词路径不变。选帧路径不自动写Blocking，不自动猜测骨骼动作语义、服装或外观。天气仅作为预演参数，不自动进入提示词。
- 绑定帧白模/深度本地下载ZIP，含PNG与manifest（Shot ID、绑定ID、帧时间、预演revision、资产哈希、相机、深度范围等）。不上传、不接入或虚构ComfyUI深度控制节点。

## 验证

覆盖归属校验、采样一致性、不可变历史、版本失效与采用前置条件、无副作用预览、正文对白不变及无生成任务；前端覆盖时间帧传递、冻结与版本检查、双路径可达、缺模型拒绝导出及manifest追溯。

- `go -C backend test ./... -count=1` 与 `go -C backend build ./...`：exit 0（service 47.722s）。提示词沿用现有项目策略及配置Skill。
- `npm --prefix frontend test`：341/341通过；`npm --prefix frontend run build`：exit 0。预演组件47.61 kB / gzip17.35 kB，仍懒加载。
- 浏览器隔离测试桩：1秒绑定已有Shot、冻结X=2姿态、预览不写回、显式采用、白模ZIP含追溯manifest、编辑清草稿/未保存禁绑、保存新revision使旧绑定过期均PASS。目视确认过期原因及禁用按钮。没有调用真实图片或视频生成。
- GLB本体缺失不允许历史导出；白模/深度仅本地下载，尚未连接真实ComfyUI深度工作流。
