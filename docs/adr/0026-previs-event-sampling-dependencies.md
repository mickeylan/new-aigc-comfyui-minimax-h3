# ADR-0026：同对象火烟采样依赖附着/飞散变换（E3）

- 日期：2026-11-28
- 状态：两阶段采样已实现；自动回归与隔离WebGL数值检查通过，产品场景/剧情验收未完成
- 关联：ADR-0024 E1/E2；仅本节点 E3

## 问题

`previsEvents.ts` 在单次列表遍历中同时修改对象 TRS 与创建火烟粒子。火烟若位于同对象附着/飞散之前，会读取还原后的编辑姿态；若位于之后，则读取本次时间采样姿态。相同事件集合仅调换顺序即可改变粒子锚点。

## 决策

1. 运行时绑定完成后，仅在内部划分采样阶段：先全部附着/飞散，再全部火/烟。保留各阶段内部顺序，不排序或改写会话事件清单及旁档。
2. 每次采样仍先释放上次粒子并还原借用 TRS，然后在同一全片时间计算变换，最后从变换后的对象世界位置生成火烟。演员骨姿仍由上游共享采样器先计算。
3. 保留现有火烟语义：offset 为世界轴偏移，粒子形状与 scale 使用既有确定性公式；不新增旋转/缩放继承，不将其宣称为物理模拟。
4. 保留半开区间 `[start,end)`、任意 seek、停止/失败还原、粒子释放及重复 stop 语义。沿用现有同对象附着/飞散重叠拒绝与附着目标链式变换拒绝；不扩展通用依赖图。
5. 不变更事件类型、旁档版本、v6/v7 schema、提示词、UI 或导出协议；不调用 Agent，不提交推送。

## 验证计划

- 新增回归：附着/飞散分别与同对象火、烟组合，覆盖全部六种列表排列；断言粒子世界锚点来自本次变换，且粒子顶点与对象 TRS 对排列不变。
- 覆盖非单位场景变换、移动骨骼、重复采样、乱序 seek、事件起止边界、停止还原和派生资源释放。
- 共享采样器覆盖同对象效果与变换在真实时间轴中的依赖，以及失败还原。
- 每个文件修改后立即运行对应检查；再运行相关回归、项目测试与构建。记录实际 exit code/断言计数，不以测试代替浏览器像素或剧情验收，也不声称宿主 gates 通过。火烟自身透明混合顺序不在此次修订范围：像素只在保持火烟相对顺序的分组内比较，不能把锚点/顶点对全排列不变扩大为全排列像素不变。
