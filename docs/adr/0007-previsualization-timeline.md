# ADR-0007：预演时间轴与受控Agent计划

状态：用户批准先记录再实现。

本期取代ADR-0005中不做路线、相机关键帧的范围限制，其余旁路约束继续有效。不做骨骼动画、天气、视频/深度序列导出或生成链接入。

采用预演schema v2，v1继续读取。时间为整数毫秒，时长1至120秒；最多32对象、12静态机位、32路线、256对象关键帧、128相机关键帧，128KiB请求限制不变，超限拒绝、不截断。路线A/B是同一对象的起终点，不是两个备选方案；关键帧以稳定对象ID归属，相机帧内含完整机位并以cut标记硬切。线性位置插值、最短弧朝向插值，播放头不持久化，不修改静态基础文档。

Agent只读取用户提供的预演文档和命令，不读取参考图、Shot、对白或站位。返回结构化问题或可审阅操作计划，不执行任意代码。首期仅支持已有对象路线、整体位移/朝向帧和相机帧；不自动添加人物或推断骨骼动作。计划绑定本地文档内容版本，明确确认后由确定性代码应用；可选择部分操作，任何编辑使旧计划失效。执行只修改本地预演草稿，持久化复用唯一PUT及revision/正文CAS；撤销仅限当前会话，撤销保存后的修改也必须产生新revision，绝不回退数据库revision。

时间轴不自动进入提示词/Blocking：原有采用链始终使用静态基础站位，而非播放头。用户可继续静态预演与提示词路径，动画只是旁路建议。

测试契约：静态场景组件继续禁止自带requestAnimationFrame；新增独立时间轴组件负责播放，测试验证循环按需启动并卸载取消。未知schema测试改为拒绝3，新增v1/v2兼容测试。播放帧只更新复用场景对象transform，不每帧重建几何体。
