# ADR-0002：Scene 媒体替换与执行完整性边界

- 状态：Accepted
- 日期：2026-10-30

## 决策

1. 维持模块化单体，不为媒体生命周期另建服务或引入新框架。
2. Scene 图片/视频替换共用事务内失效原语：投影切换、帧候选清理、连续性下游失效及相关执行产物失效必须原子完成。
3. 最终编排以实际片段序列为准，而非以较早的计划快照推断。
4. `MergeTask` 重试保留原输入快照；输入变化时不得静默替换，必须失效并由用户重新确认。
5. 门禁仅覆盖文件归属、时长等执行完整性；不增加对白、运镜等语义门禁。

## 后果

历史候选采用与普通替换遵循同一失效规则；重复采用当前候选保持幂等。生成成功后自动成为当前候选的既有策略不在本决策中改变，后续如需调整应另作产品决策。
