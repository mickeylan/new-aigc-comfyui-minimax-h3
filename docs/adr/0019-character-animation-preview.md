# ADR-0019：3D 角色内置骨骼动作预览

状态：七项功能已实施并验证；用户已批准提交与推送。以下各阶段的“未提交”标记为当时验收状态。

## 决定与范围

- 延用现有 React/Three 岛及 Three AnimationMixer，不引入依赖、不合并 video-editor 时间轴。
- 第一刀只支持导入 GLB 中已存在的骨骼局部 TRS 动画，过滤对象根节点、材质和相机轨道；不承诺跨骨架重定向或消除滑步。
- 动画片段为本次会话预览资源，选择、播放、暂停、继续、停止。暂停保留采样姿态和控制权；停止恢复播放前的编辑姿势，不隐式烘焙。
- FK 与动作预览互斥。切换选择、删除、隐藏、锁定、载入新场景、卸载时停止并还原，清理 Mixer 绑定。
- 保存工程、导出几何、复制和骨姿记忆前自动停止并还原，再执行原操作；不把预览中的临时帧写入存档或历史。指纹检查使用播放前骨姿，预览本身不制造脏标记。运行态不持久化；首期导出仍是静态姿势，动作片段不随存档保留，界面明确提示重新导入带动作原 GLB。
- 后续对象轨道与动作片段、A/B 路径使用共同时间采样；本刀不实现对象时间轴、动作库、动作混合或路径同步。

## 验收要求

真实 AnimationMixer 与带骨架模型验证采样变化、暂停稳定、继续、切换片段、停止精确恢复；非法轨道拒绝、根变换不动、释放后不再推进。浏览器验证选择/播放/FK切换及保存保护。每项只按实际结果记录，不把合成样本等同外部Mixamo资产全兼容。

## 第二刀：A/B 动作联动预览（用户“继续”授权）

- 路径面板独立选择移动目标的内置片段，默认为“不播放动作”；选择是会话状态，不修改存档版本。
- 位移和骨骼按同一个绝对 elapsed 秒采样；片段按原速循环，不自动按路径长度缩放步频，不保证无滑步，带根骨平移的素材应优先使用原地走跑片段。
- 此刀只接路径预览，未接相机播放、首尾帧或序列导出。保持原路径预览结束停在终点的行为；停止/取消还原骨姿，位移留在当前位置，撤销可回到移动前。
- 路径播放拥有独立停止入口；编辑、FK、保存、切换选择、隐藏、删除、卸载均同步取消路径调度及骨骼控制权，不留下独立 Mixer 时钟。
- 验证包含绝对时间乱序采样一致性、骨姿恢复，以及浏览器真实路径/骨架联动与停止/保存/撤销保护。

## 第三刀：相机跟拍动作预览（已授权补充后实施）

- 复用路径面板选择的内置动作，仅在勾选跟拍且存在有效移动目标与路径时生效。相机、位移、骨骼统一使用相机预览 elapsed；位移到 B 后停止，骨骼冻结在移动结束时的采样时间；总预览时长沿用相机路径时长。
- 新增“停止跟拍预览”。自然结束、主动停止、编辑、保存、换场景及卸载共用幂等收尾：取消 rAF 和兜底定时器、释放动作绑定、还原原骨姿以及角色位置/朝向，迟到回调不得写新场景。
- 与第二刀区分：独立路径结束保留位置，相机跟拍预览结束还原角色位置；相机保持原有预览落点行为。
- 仍为会话预览，不实现序列/首尾帧动作导出、动作持久化、无滑步或统一对象时间轴。

## 第四刀：参考序列与视口首尾帧动作采样（已授权）

- 保存/几何导出仍先停止交互预览，读取编辑骨姿；参考序列与首尾帧则在停止交互预览后独占同步取图窗口，输出临时动作采样，不改变提示词或模板。
- 复用路径动作选择。序列时间范围仍取相机与移动较长者；首尾帧取相机两端时间。骨骼采样时间钳到移动时长，之后冻结；有有效路径与移动目标才采样动作；跟拍时叠加水平位移。
- 同步复制画面后、异步PNG编码和上传前恢复骨姿与临时角色变换，finally释放绑定；代次/对象身份/显隐锁定校验阻止旧导出继续。
- 不增加动作持久化字段、不改存档版本，不保证步幅匹配或无滑步；失败可能留下已上传的首帧，不能宣称上传事务原子性。
