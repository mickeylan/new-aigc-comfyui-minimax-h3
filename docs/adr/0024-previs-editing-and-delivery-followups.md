# ADR-0024：预演观察、编辑与交付增量（P0/P1/P2）

- 日期：2026-11-27
- 状态：用户明确允许忽略旧工作流挂起继续；A/B、C1/C2a/C2b/C2c/C3、D1/D2静态诊断、E1/E2、F1/F2/F3、G1/G2/G3已接入，完整范围与视觉验收仍有未完成项（见下）
- 路线文档：../toonflow-followup-roadmap.md

## 背景

用户要求先记录Toonflow对比，再逐一实现P1/P2。复用ADR-0023已有小说理解与执行规划，不增加分析器。当前已有镜头表、执行节拍、人工替换/拆段、共享采样器及v6/v7保存回读；不把上游schema迁入视为功能已接入。

## 决策与分期

### A/B：视口观察与运行诊断

新增只读审阅入口，复用createScriptShotSampler；在开始/结束及镜头切点/动作边界和最多0.1秒间隔采样，预算6000点，超预算明确阻塞。每镜起始实际视口PNG与JSON一起本地ZIP交付；PNG来自真实renderer的现有captureViewportAt，不由CPU推测。报告记录场景编辑指纹、计划内容、镜头/绝对与镜内时间、实际相机、演员初末位置、walkProof/contactMetrics及完成/阻塞状态，visuallyApproved固定false。离散诊断不是连续无碰撞证明，截图不是剧情视觉通过；不测闭合握持。采样会话在任何异步编码前停止并还原，修订/取消检查在每次await之后执行，变更则整包丢弃；不存档、不调模型、不自动修改场景。

A2/B2：观察入口显式增加时序证据模式：每镜起点、中点、镜尾前min(1/24秒,镜长/2)，加执行beat起止边界（严格在本镜[start,end)内）；相同秒去重且排序，不采镜头end冒充本镜末姿。最多96张PNG、整包图像字节≤128MiB，超过预算整项blocked、不截断，不发布半份截图。保留observePrevis旧默认起点模式供旧调用者；Stage显式启用时序模式。报告明确capturePolicy、各帧全片/镜内秒、actual camera和活动角色beat/片段名（仅计划元数据，不作为动作完成证据）。附无脚本的review.html，以相对安全PNG路径展示时间定位、权威对白及截图，转义所有外来文本，固定visuallyApproved=false；失败报告无残留图或半份审阅页。共享采样、stop-before-await、取消/修订边界不变，不调用模型、不改提示词/计划/存档；这是视觉证据丰富化，不是AI视觉反馈修订闭环完成。

### C：时间轴

C1先在现有逐段骨骼纠正面板接入可视化镜内时间轴：各执行角色独立一行，按原start/end占比显示节拍，点击选择既有角色/段；键盘原生按钮可操作。显示镜内秒，不与全片绝对时间混淆。角色缺失/隐藏/锁定、busy、stale及存在未暂存修改时禁止切换，选中同步原下拉框；切换镜头/计划清空选择。

选择不修改计划、不播放、不写库、不调用模型。替换/拆段继续通过correctExecutionBeatClip和原暂存→重新确认→几何预检→应用边界，保留对白、镜序、总区间、线性根轨迹、接触及原始来源。无需新存档字段。选中不自动滚动真实视口或改变演员姿态。

C2a：增加1/2/4/8倍共同时间尺度横向缩放、键盘可用的镜内时间游标、0.1秒或节拍边界吸附及该时刻活动段只读摘要。游标明确只是审阅标尺，不播放、不改变真实视口，也不冒充实时播放头；使用镜内时间、显示对应全片秒。计划/镜头切换重置游标，busy/stale/dirty禁用；不修改对白/节拍/源片段。实际播放头联动与拖动时长仍未开放。

C2b：允许显式调整同角色两段相接静止动作的共享分界，使用镜内秒数值框及键盘/指针range，范围限两段并集内部、两侧均超过1e-6秒。必须同位置同yaw且原区间严格相接；带位移、转向、间隙、末段或同时拆段/换片段均拒绝，不把根轨迹重定时隐藏在改时长里。保留原片段/来源索引、全部对白与其他轨道，镜头和两段并集总时长不变。两段仍各自从零播放、短片段末帧停留，不拉伸不循环；会改变动作切换时间和第二段采样相位，非源区间/速率编辑，可能跳姿，须重新审阅。纠正写append-only审计记录，仍走暂存→重新确认→几何预检→应用。只改变现有start/end与diagnostics，不新增v6/v7字段。UI显示待暂存分界，不在拖动时修改计划或真实视口；busy/stale/角色不可用时拒绝，切换计划清草稿。

C2c：新增已应用计划的只读真实播放轨道。Stage仅把共享session.sampleAt返回的seconds/index连同此次原计划引用传给面板，不用UI定时器估算时间；约10Hz发布显示状态，切镜/对白变化立即发布，采样仍每rAF执行。播放计划引用必须等于当前appliedPlan；无采样、计划不同、非法时间或镜索引时不显示，不拿草稿轨道冒充已应用计划。显示全片秒、镜内秒、多演员半开区间活动段和统一比例播放线；停止/失败/换场沿原stop清空。只读轨道无拖动seek，不自动滚动或切纠正草稿、无网络/存档字段变化。原C2a审阅游标继续明确不播放，C2b编辑在播放中仍禁用；显示节流不是诊断采样精度或连续视觉通过。

C2d：已应用计划新增独立全片24fps定位滑条，帧号0至ceil(total*24)-1，秒数frame/24，严格不以片尾end冒充上一镜末姿；切点沿共享sampleAt半开镜头语义。拖动只调用现有逐镜会话的单次采样分支，不启动rAF、不自动续播、不改计划/对白/源区间/速率；实际采样结果仍进入真实播放头。定位期间借用视口姿态并沿shotPlayback锁住编辑/导出，显式停止、再次定位、连续播放、失败、卸载或换场走原stop还原机位/根TRS/骨姿/事件及指纹遮罩。滑条在定位期间仍可操作；普通播放中禁用，先停止再定位。每次启动先stop并生成token；懒加载前记录场景epoch、编辑指纹、计划内容和会话事件，await后复核，停止/快速连续拖动不得迟到启动。无新存档字段，不调用模型。定位只是预演姿态，不是保存的编辑，也不构成视觉通过。

C2再扩展缩放、吸附、播放头等视图能力；拖动改时长、源入出点与速率需要独立契约和共享采样能力后才能开放。不能先画可拖UI却暗中改变原对白时间，不能把C1称完整多轨自由编排完成。

### D：多主体镜头候选

复用已确认演员ID、真实bounds和镜头表，只提出机位候选、轴线风险，不自动增人、不替换导演镜序和时长。视锥入画不代表无遮挡；遮挡需另有真实几何/像素证据。

D1：仅为已有execution actors或motion目标生成三个静态机位候选，按实际对象bounds及根位移端点并集构成保守取景框；不是完整骨姿扫掠体。按当前画幅与透视FOV拟合并检查8角视锥，记录首两主体的有向轴及相对既有机位的越轴/轴上/不可定义风险。只可人工明确选用，通过修订复核及既有应用几何预检后替换指定镜头camera；不改镜序/时长/对白/动作。已有execution.camera轨道拒绝静态覆盖，需先显式另行编辑轨道。无主体/退化bounds/重复身份/超界均拒绝。未计算遮挡和动态骨姿包围体，候选不是导演或视觉通过证据。

D2：对已生成候选另行显式执行编辑姿态遮挡几何诊断，不改变D1的occlusionTested=false或自动选机位。对主体每个根位移端点的编辑包围体中心+8角发射有限线段，测试非主体可见静态Mesh的双面三角形；报告命中射线数、对象ID及检查预算，不输出可见像素比例或“无遮挡通过”。所有执行主体相互遮挡、动态骨姿/根轨迹中间时刻、环境地形/天气/事件不在本诊断内。透明/alpha/自定义材质或回调、骨骼/动画/morph/实例/泼溅等不可可靠测试时整项标记不可用，不能跳过后声称完成。≤128条目、2048层级节点、256静态Mesh、300000顶点、100000三角形、512射线、射线×三角形≤2000000；超预算不截断，整项不可用。克隆层级/geometry/material后按世界矩阵构造测试Mesh并DoubleSide，不触碰原对象、材质side或geometry bounds缓存；所有派生资源finally释放。诊断绑定生成候选时的plan/revision；计算前后复核，busy/计划/选镜变化清空，采用仍沿原确认与安全预检，不以命中0冒称可用视觉机位。

### E：附着与事件效果

分开实施道具骨骼附着和火烟/飞散。与现有腕接触不同：附着必须定义目标骨骼、局部变换、生命周期与停止还原，禁止以父子关系证明闭合握持。火烟属于可重复时间采样的参考效果，不宣称物理燃烧；仅已有部件飞散不能称真实断裂模拟。未支持项显式拒绝；新持久数据先定兼容方案，不无声升级v6/v7。

E1：先提供明确标注“不随存档保存”的会话事件层（WeakMap绑定真实对象，不写userData或v6/v7）。支持已有道具根对象按唯一实名Bone、局部位置/旋转/缩放附着；火/烟采用固定32粒子确定性参考；飞散只平移旋转已选独立对象，不拆网格。事件使用全片显式[start,end)秒区间，最多32事件，重叠附着/飞散同一对象拒绝。对象必须可编辑；演员执行对象不可同时充当附着道具/飞散部件；目标骨骼不存在或重名阻塞。共享采样器在骨姿计算之后执行事件，因此播放、观察、PNG和视频使用相同时间语义；任意seek先还原事件对象，停止/失败恢复原本父级与TRS，派生粒子由共享采样会话持有，停止/失败释放；观察及单帧试演在await前停止，视频沿用现有编码会话的所有权与finally恢复，不承诺整个视频编码期间编辑图不被临时借用。UI提供显式预览采样和清除；会话事件清单附于观察报告，不声称保存回读已支持。完整持久化/导入属于后续兼容契约，不隐性写新格式。

E2：不改v6/v7，使用独立JSON事件旁档持久化，kind=previs-event-sidecar/version=1。旁档绑定已应用镜头表及对象ID/名称/基础TRS/有序骨骼名的内容快照（不使用运行期UUID/epoch），内容快照一致的存档回读后允许重新导入（真实产品存档往返尚未验收）；绑定快照不一致则拒绝，不按名称猜配或迁移ID。导入先解析为待审阅草稿，显式确认后经现有write原子验证全部对象/骨骼/区间再整体替换；无效或过期草稿不改变现有事件。限制UTF8文本128KiB、32事件，拒绝未知字段与畸形类型，JSON不执行代码；导出只生成本地旁档，不写业务库。导入草稿在场景切换后清除，事件列表变化同样使草稿失效。此项是可重导入旁档，不冒称场景自动携带事件。

E3（详见ADR-0026）：同对象火烟依赖本次附着/飞散的变换，内部稳定分两阶段采样：先所有附着/飞散，后所有火烟；不改外部事件清单或旁档。每次seek先restore，保持骨姿在事件前，半开生命周期及链式附着/变换重叠拒绝不变；offset仍世界轴偏移。不引入通用事件ID/触发图，不支持附着释放后的连续弹道接力。火烟内部顺序保留，透明混合可随火烟彼此排序变化，不能把锚点不变冒称全排列像素不变。

E4/E5（详ADR-0027）：已读取会话事件列表展示完整JSON和全片半开区间，单项删除/区间调整均先准备再单独确认，绑定全列表内容与序号。重复事件只处理选中项；过期拒写、宿主错误保留原事件。区间只改start/end，不改镜长/对白，按新start重新计时，不承诺连续释放。成功修改清旧截图和待确认旁档，异步预览前后事件/来源快照变化拒图；disabled/切场释放URL。没有后台外部变化监控承诺、不改schema、通用依赖图仍未完成。来源补强使删除/调整草稿在有sidecarSource时同时绑定来源，确认时来源变化或获取失败均清草稿零写入；无回调旧宿主只保留事件列表校验。

### F：场景级合批

只增加绘制代理，保留独立编辑对象ID/姿态/可见锁定状态。活动对象、选中编辑、骨骼动画、特殊着色器等先排除；代理更新、拾取、资源引用、撤销及导出一致性须测。draw call减少与视觉一致性分别验收，不以对象数当性能证据。

F1：显式启用的视口绘制代理，仅合批同一geometry/material实例的重复静态Mesh（至少2个），不合并资产或改编辑目录。限制2000个Mesh，排除动画/骨骼/透明/多材质/自定义shader/morph/特殊回调/选中与执行活动对象，保留阴影及layers/renderOrder。原Mesh只在同步renderer.render调用内临时隐藏，finally立即还原，代理同时移除；拾取、存档、导出始终读取原对象。每次绘制核对世界矩阵、可见与身份，内容变化自动释放旧代理并重建，原geometry/material不由代理释放。UI记录renderer.info.render.calls实际信号；合批前后像素一致性仍需浏览器验收，不以代理数量宣称视觉通过。

F2：在F1默认关闭的同一视口入口中，优先重复几何实例化；余下几何不同、共享同一Material实例且属性布局相同的静态Mesh可合为单一派生BufferGeometry。仍沿F1全部排除条件；另排除局部drawRange、自定义属性、interleaved/非Float32属性及非静态用法。仅支持position/normal/uv/color/tangent普通属性、相同索引有无及布局；总合并顶点预算200000，超预算不合批而非截断原对象。世界变换烘入副本，保留原顶点/材质；缓存检查矩阵、索引/属性身份和version，needsUpdate后重建。停止/重建/卸载只释放自有合并几何，绝不释放原几何/材质。代理仅同步绘制期间挂载，finally恢复；原对象ID/锁定/拾取/存档/导出不变。材质相似不等于同实例，不跨材质UUID猜合并；低收益小样不称性能通过，GPU draw-call与像素等价仍需独立真实证据。

### G：交付包

复用当前逐镜参考与视频编码、共享采样器及来源修订，补镜头表/CSV/EDL组织。明确帧率/时间码、文件映射、取消与失效，不下载半包、不修改镜序。不重做video-editor。

G1：在现有原子逐镜PNG参考ZIP中增加shots.html、shots.csv、timeline.edl与delivery.json，不另建编码器或伪称包含视频。帧率明确固定24fps非丢帧；每个切点取最近整数帧，若短镜舍入后为空则拒绝整包。EDL源文件为每镜独立clay PNG静帧，源入点零、源出点为镜长，记录时间连续；HTML/CSV列出全部参考文件映射与权威对白（只读，不合成音频）。HTML转义，CSV防公式注入，文件映射必须来自已生成参考清单，禁止不安全路径与换行。沿用现有取消、修订检查、恢复与整包下载边界。视频仍由原有独立编码入口导出，G1不冒称视听全交付完成。

G2：在现有逐镜视频产物上提供独立统一视频交付ZIP，不重新渲染、不调用新编码器、不上传。包含同一WebM、完整追溯manifest、视频镜头表HTML/CSV、24fps NDF EDL与delivery.json；无音轨，不合成对白。只接受实际24fps产物（其他帧率继续可单独下载），EDL各镜源入出与整段WebM的绝对帧位置相同，不能沿用PNG源入点零。核对计划、帧数/时长/格式/来源当前性；打包前后及每次await后检查取消和失效，最多256MiB，失败不下载半包。事件快照进入视频manifest并参与来源失效判断。PNG参考交付仍独立，本项不声称一次下载已含所有结构PNG和音频。
