# ADR-0016：Image to Location 取景出图与场次候选

状态：已采纳，本期闭环实现及隔离验证完成；真实模型效果待验收。用户确认先记录ADR，结果进入场次分镜图候选。

## 决定

复用Studio 3D干净取景、现有图片编辑模板与任务系统，以及GenerationCandidate审阅/采纳，不另建渲染器或媒体权威。此为ADR-0005/0008/0009的窄口扩展：预演不会自动进入生成链，只有人工明确选择项目、场次、可选已有Shot，审阅提示词和参考图并提交，才创建单次任务。

服务端校验project→scene→shot归属、已启用兼容模板与实际参考图容量；快照固定为首张，额外参考图顺序不变。提示词由人编辑，不静默改写或切换模板，模板/参考图/上下文/提示词变更必须重新审阅。记录上下文、快照、提示词、模板和机位的来源信息；任务恢复不依赖浏览器内存。

结果登记为场次image候选，pending且非current，不改变当前分镜图、Scene任务字段、提示词、站位或Shot。手动采纳复用既有候选选择接口。Shot关联仅为来源，不新增Shot图片权威。固定身份迁移路径与v1–v4存档保持兼容。

## 范围

本期先完成同一场景按当前机位取景→人工提示词/模板/参考图→生成→候选审阅闭环，支持多次人工切换机位分别生成。不扩展资产商城、角色动画库、自动镜头规划或双预演文档合并；不批量生成、不调用真实AI验收、不改超时重试、不部署、不提交推送、不触碰18000。
