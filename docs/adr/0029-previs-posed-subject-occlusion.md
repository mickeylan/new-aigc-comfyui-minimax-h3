# ADR-0029：候选机位的离散实际骨姿主体互挡诊断（D3）

- 状态：已实现，几何/组件/生产回调及隔离浏览器验证通过；非Stage完整验收
- 前置：ADR-0024 D1/D2

## 范围

现有D2只测非主体静态三角形。D3独立按钮使用生产共享镜头采样器，在指定镜头起点/中点/尾前一帧（三者去重）采样真实根位移与骨姿。每次对实名取景主体逐顶点读取当前Mesh/SkinnedMesh（含morph/skin）世界坐标构成AABB，用候选机位向主体中心和8角发有限线段，测试其他主体同时刻AABB，分别报告时间/命中数/阻挡身份。候选不改变真实机位或计划。

此为实际骨姿的包围体互挡风险，不是三角形/透明度/像素可见率，不证明零命中即无遮挡，不处理静态布景/环境/事件或连续轨迹；与D2结果分列，不自动采用候选。单主体无互挡对象仍不得称视觉通过。

## 安全与预算

同步临时采样，finally必stop还原，任何采样/几何/预算/来源校验失败整项不可用，不返回半份诊断。先检查主体数≤32、节点≤2048、总顶点≤100000，且三时刻顶点总读取≤300000；拒绝实例、泼溅、自定义顶点方法、非有限/空几何等不支持项。不修改原几何/骨姿/材质缓存，不建替代动画解释器。所有参与候选须同一来源，计算前后检查plan引用与内容及场景指纹，失败清结果。无模型/提示词/schema/后端变更、不提交推送。

## 验证

用实际Three骨骼顶点验证骨姿改变包围体、同一时刻主体互挡、失败还原/预算/非有限拒绝；宿主通过共享采样器生产接线。逐文件验证、独立全量Vitest与build，浏览器隔离交互不得冒称真实Stage剧情验收。
