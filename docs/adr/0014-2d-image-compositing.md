# ADR-0014：2D多图片层合成与文档导出

状态：已采纳；用户同意先记录再实施，透明度和显隐采用图层字段。

## 决定

- 复用现有 Konva / SceneState，不新增依赖、后端表或第二套图层模型。drawNodes 数组顺序是唯一叠放顺序，底图仍独立存在。
- 保留替换底图入口，新增独立的多图片层入口；复用节点移动、缩放、旋转及排序能力。
- layerOpacity 与 visible 是文档字段，与笔刷 opacity 区分。撤销、重做、复制和JSON导入导出保持字段；旧文档缺省为完全可见。显隐不移除节点、不改变叠放顺序。
- 下载和写回共用文档级PNG导出；输出尺寸取文档尺寸，不受视口平移缩放影响。不导出棋盘格、选框、蒙版、光标或变换手柄，操作后恢复编辑器状态。
- 3D维持现有平面/天空盒/身份迁移模型；无证据缺口不扩大改动。

## 边界与代价

不新增混合模式、分组、云端图层存储或真实生成验收。图片层增加浏览器内存消耗，按画布尺寸适配显示但保留原始图片。合成PNG是跨流程交换产物。

## 验证

已实现节点字段、历史/JSON往返与导出状态恢复；新增6个行为用例、3个宿主接线用例。前端完整测试通过（node:test 636个、Vitest 64个），生产构建退出码0。

浏览器隔离夹具通过双图片上传、50%不透明度像素混合、显隐保序、排序后像素、变换事件及撤销、1024×1024文档PNG导出验证。导出忽略入场动画的临时透明度，但保留权威图层透明度；成功或异常后均恢复编辑器状态。未执行真实AI生成或业务写回。
