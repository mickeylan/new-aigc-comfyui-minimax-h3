# ADR-0028：事件全片区间时间轴（E6）

- 状态：已实现；组件/集成回归及隔离浏览器通过，非Stage端到端验收
- 前置：ADR-0027 E4/E5

## 契约

已读取事件按原序各占一行（重叠和重复不合并），展示序号/类型/对象及全片半开秒数。宿主读取已应用计划末镜end，与读取事件一同捕获为标尺快照；不使用未应用草稿、最大事件结束或固定600秒冒充全片。无有限正时长降级为文字列表并明确说明，不绘制假比例。非法/越界事件显示原值与不可绘制提示，不静默夹取。

有效区间按start/duration、(end-start)/duration绘制比例条，文字置于独立按钮避免短区间文本溢出。点击/键盘激活事件仅调用现有E5准备入口，删除草稿互斥、绑定列表和来源，仍需单独确认。禁用或异步取图中不能准备。不得写入、播放、取图或变更计划/事件/schema，不支持拖动自由编排。时间轴是读取快照，外部修订仍由确认门禁拒写。

## 验证计划

新增比例、重叠/重复、无时长、非法/越界、禁用和点击零写入测试；集成复用E5快照与来源门禁。逐文件测试，完整独立Vitest和Vite build；浏览器检查深色窄屏可读性，不称Stage剧情或存档往返完成。不改提示词、不调用模型、不提交推送。
