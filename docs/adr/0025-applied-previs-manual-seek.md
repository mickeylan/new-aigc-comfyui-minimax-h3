# ADR-0025：已应用 scene3d 计划的真实手动 seek（P1 C2d）

- 日期：2026-11-28
- 状态：决策已记录，实施与验证结果以本轮执行报告为准
- 前置：ADR-0024 C2c 的真实只读播放头；共享 createScriptShotSampler 随机访问与基线还原

## 决策

以下以ADR-0024 C2d及实际生产实现为准，收窄早期草案中尚未实现的暂停恢复/终点/同会话复用设想。

1. 仅对当前已应用计划开放独立24fps全片帧号range，帧0至ceil(total*24)-1，秒数frame/24；不允许全片end采样冒充最后一镜末姿。C2a游标仍只是标尺，纠正草稿不作为定位来源。
2. 每次seek先stop精确还原，再通过现有逐镜入口重新建立共享采样会话，只调用一次sampleAt并保持临时姿态。复用真实对象/clip/几何/环境预检，允许前后跨镜；不复用上次借用姿态作基线。请求帧不是成功证据，实际秒数/镜序/对白来自采样结果并立即发布。
3. 定位分支不启动rAF或播放计时器，不自动续播。普通播放中禁用定位，先停止再操作；定位保持中仍可再次seek。连续播放按钮仍沿现有宿主禁用策略，先停止定位再播放，不增加暂停恢复时钟。
4. 停止、失败、换场和卸载沿既有finish/stop还原相机/控制器/根TRS/骨姿/事件及指纹基线。每次启动使用token，懒加载前后复核场景epoch、已应用计划引用及内容、编辑指纹和事件快照，拒绝迟到启动及过期来源。计划的编辑/替换仍沿原宿主停止链。
5. busy或普通播放中禁定位；定位保持中锁住其他编辑/导出但允许重新seek及停止，未发布保持状态前也可停止以取消迟到启动。它独立于未应用的纠正草稿，不宣称已拦截面板内部dirty/pending；实际只读取当前已应用计划，不自动采用草稿。

## 范围

只改 scene3d 会话控制、现有时间轴 UI 与对应测试。不改对白、存档 schema、提示词、后端模板；不调用 Agent、远程生成、不提交或推送。保留既有未提交改动。不把自动测试或隔离夹具称为产品视觉验收，也不声明 host gates 已通过。

## 验证

按文件执行定向测试，再跑相关回归与前端构建。断言真实共享采样的跨镜前后 seek、骨姿与机位、字幕/半开活动段、暂停后旧回调无效、停止精确还原、非法时间/非当前计划拒绝、迟到启动与失败清理。组件断言原计划引用、禁用边界、键盘可用原生 range、停止可达及不改计划/无网络。记录实际命令、退出码和计数；未执行的浏览器验收明确保留。
