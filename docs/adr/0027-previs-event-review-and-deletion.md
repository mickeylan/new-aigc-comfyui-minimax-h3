# ADR-0027：会话事件逐项审阅与删除（E4）

- 状态：E4/E5已实现，组件回归与隔离浏览器交互通过；非Stage完整端到端验收
- 前置：ADR-0024 E1/E2、ADR-0026 E3

## 决策

- 在既有事件面板只读展示已读取事件顺序、类型、对象ID、全片半开区间及完整参数；实名目录仅作辅助，不按名称猜配。原事件JSON仍可审阅，React文本转义，不执行内容。
- 每项提供“准备删除”与单独“确认删除”两步；待删对象绑定已读取完整列表的内容快照与序号，不按内容filter删除，重复火烟事件仅删一项。准备不写入、不改视口；切场/重读/追加/清空/导入后清待删草稿。
- 确认前重新read并核对完整快照、序号及目标内容；过期拒写、清草稿，要求重读，不按新列表相同序号删除。write继续走Stage现有原子验证与失败回滚。write抛错时不更新UI列表，不暗删其他项。busy/pending禁准备及确认，放弃可用。
- 成功修改事件后清除旧预览图与旁档待确认草稿。异步preview前快照事件、可用时旁档来源；await后先核对scene generation、事件及来源。失效不创建URL、不展示迟到图；成功取图后遇disabled或场景切换清图并释放URL。无独立后台监测承诺，未发生刷新/操作的外部变更仍由Stage操作时校验。
- 不改事件、旁档或v6/v7 schema，不添加依赖ID，不修改采样、火烟透明顺序、提示词或后端。不是撤销历史或通用事件自由编排，不调用模型，不提交推送。

## E5：显式调整已有事件全片区间

- 每项另有“准备调整区间”，与删除草稿互斥；数值框只改该事件start/end，其他参数/其他事件/顺序均保留，不修改计划/镜长/对白。必须有限非负、end>start、end≤600且与原值不同；宿主write进一步校验全片时长、同对象区间重叠及资源。输入空白/无效/无变化禁确认，不暗中夹取或自动延长镜头。
- 显示全片半开区间、新旧值、事件仍按新start重新计时；飞散t=seconds-start改变轨迹相位，附着结束回编辑姿态，火烟相位改变，不承诺释放连续弹道或物理模拟。只有单独确认才写入；不是拖动自由编排或动作片段源区间编辑。
- 与E4相同的完整列表内容快照及序号绑定；过期拒写，失败保留现有事件及待改表单便于修正。重读/切场/删除/追加/旁档替换清表单；成功调整清旧截图/旁档草稿。使用现有write回滚，无新schema或自动保存。

## E4/E5来源修订补强

准备删除或调整时，若宿主提供sidecarSource，须成功捕获其来源快照（计划及对象内容）；确认前除事件列表外再次复核来源。来源不同或读取抛错一律零写入并清除对应草稿，提示重读重备；准备读取失败也清除旧草稿，不能复用旧确认。来源稳定正常写；没有来源回调的旧宿主保持仅事件列表校验兼容，不宣称具备来源保护。宿主write失败仍保留草稿，不与来源失效混为一谈。无schema/自动存档变化。

## 验证

新增组件测试覆盖只读列表、重复事件只删一项、两步显式确认、列表过期/重排拒写、write失败保持、busy/切场、异步事件/来源变化拒图及URL释放；保留既有断言。逐文件定向测试，再运行独立全量Vitest与build。完整npm test已知跟踪import失败未消除，不暂存绕过或无变化重跑。涉及画面只用隔离无真实数据夹具；产品端到端与剧情通过另行验收。
