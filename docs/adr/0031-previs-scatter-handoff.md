# ADR-0031：附着释放后飞散接力（E8）

- 状态：已实现；单元/生产采样回归与隔离浏览器通过，非Stage端到端验收
- 前置：ADR-0026 E3、ADR-0030 E7

## 契约

同一对象存在“附着结束时间 = 飞散开始时间”（差 ≤1e-9）时，视为释放接力，飞散不再从编辑姿态起算，而从**当前采样时刻该附着骨骼的世界姿态**起算：位置 = 骨骼世界位置叠加局部偏移，旋转 = 该世界旋转；随后仍按 `position += velocity*t`、`y -= 4.905*t²`、`rotation*t` 的既有弹道推进。

不新增事件字段、不改旁档/存档/schema：接力完全由既有区间连续性推断。区间不连续（有间隙或重叠）时不接力，仍在编辑姿态基础上弹道；重叠沿既有拒绝。速度始终是用户填写的初速度，**不**从父骨骼位移/旋转推算动量或线速度，也不继承父骨骼的缩放以外任何隐式状态。

释放姿态依赖父骨骼当前采样状态：若该父级在当前时刻未生效（例如链式父附着已结束或尚未开始），退化为父级的当前编辑姿态。工具不重放历史轨迹、不插值“放手瞬间”的中间过程，也不保证连续或物理正确；`attach` 与 `scatter` 都是确定性快照运算。

骨骼缺失、重名、目标被移除/隐藏/锁定/换父、非有限数值、超出全片区间均整次失败并还原，不产生半份姿态。不引入通用依赖ID、触发条件或图编辑器；不调用模型；不提交推送。

## 验证

新增用例：连续边界确实从释放姿态起算（与结束前一帧姿态对比）、间隙时回退编辑姿态、速度仍为填写值（不同速度下同刻位移差符合公式）、旋转按释放姿态叠加、链式父未生效时退化为编辑姿态、骨骼移除失败并还原、stop 与效果结束后还原、共享采样器一致。逐文件验证后运行独立全量 Vitest 与 build；隔离浏览器验证真实 WebGL 下释放衔接与还原，不称 Stage 剧情验收。

## 实际结果

- 接力由区间连续性推断（`abs(attach.end - scatter.start) <= 1e-9`），未新增字段；旁档/存档/schema 不变；一个飞散若匹配到多个同对象附着来源时拒绝（写入层同对象区间重叠已先拒绝）。
- 新用例7项通过：连续边界从释放骨骼姿态起算、速度只改速度时位移差符合公式、有间隙回退编辑姿态、旋转在释放姿态上叠加、链式父未生效时退化为编辑姿态、多义/缺骨/中途移除拒绝并还原、生产共享采样器一致且stop还原。旧事件/链式/UI回归未改期望。
