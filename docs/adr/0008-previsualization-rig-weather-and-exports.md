# ADR-0008：预演骨骼动画、天气与白模／深度导出

状态：已确认并实现 GLB 导入＋模型内置蒙皮骨骼动画片段、天气、白模／深度与序列导出；未提交或部署。

本期扩展ADR-0007的预演文档，仍是旁路：不进入生成链，不改Scene、Shot、对白、站位与提示词。

骨骼动画：支持自包含、未压缩 glTF 2.0 二进制 GLB 的骨架／蒙皮及内置动画片段，使用 three.js GLTFLoader 与 AnimationMixer；不以刚性木偶替代。每对象可绑定一个片段，设起止时间、循环或末帧保持；与既有世界位移／机位时间轴按相同时间采样。优先使用原地片段，模型内置根位移暂不自动消除或重定向，界面明确提示可能与路线叠加；不包含跨模型骨架重定向或动作混合编辑。

文档升至 v3，保留 v1/v2 双读；服务端持久化 SHA-256、对象绑定、文件名、片段索引与时间参数，不保存或转发 GLB。二进制以内容哈希存于当前浏览器 IndexedDB；换设备、清缓存或文件缺失明确提示，导出禁止静默退回占位体。重新导入同文件可恢复。模型限32MiB、50万顶点、2048节点、256片段、32张纹理；纹理单边≤4096，总像素≤32Mi像素；禁止外部资源 URI 和必需扩展解码器。用户负责素材许可；本仓库不附带第三方角色模型。

天气：预设晴天、阴天、雨、雪、雾五档，加强度、种子、太阳高度角与雾密度。种子决定粒子分布，同种子同预设必得同分布，便于复现与导出。天气只影响预演渲染与导出画面，不写入提示词，不影响生成参数。

导出：分辨率1280×720；序列支持1/6/12/24 FPS，最多240帧、256MiB，浏览器本地ZIP附manifest。序列区间为起点包含、终点不含；可取消且不下载残缺序列。白模采用中性材质与可辨识体积的光照，排除网格、箭头、标记及选中高亮。深度导出使用8位线性灰度（近白远黑），由透视深度反算相机空间距离；相机裁面保持原值，灰度映射范围可调（默认0.1～50米），manifest记录两者与文件清单。排除辅助几何、天气粒子和雾；不能把深度直接称为通用控制输入；目标节点兼容性须实测。导出当前播放帧或按所选帧率导出序列，文件按帧序号命名并附manifest.json列出帧率、分辨率与文件清单。导出在浏览器本地完成，不上传服务器、不进入ComfyUI工作流；是否接入深度控制必须由目标工作流的实际节点验证，不能把深度图当普通参考图使用。

边界：骨骼动画与天气不改变Scene正文与对白；导出白模与深度仅为参考素材，需要用户显式上传并人工确认；程序不自动改写提示词、不自动提交生成任务。
