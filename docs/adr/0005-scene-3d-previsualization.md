# ADR-0005：Scene 级轻量 3D 预演旁路

状态：采纳。用户批准先记录 ADR，并允许 three.js 懒加载。

## 决策

- Scene 子面板保存带 schema_version 的预演文档：命名着色低模人物与道具、真实角色/look/道具来源绑定、位置朝向、相机位置/目标/视角、画幅及命名视图。
- three.js 仅打开面板时动态加载，独立渲染块；发布前报告实际 gzip 包体并保留 MIT 许可声明。后端只校验和持久化 JSON，不使用服务器 GPU。
- 提供顶视、透视、摄影机画面、机位构图与 PNG 下载。低模仅表达空间，不臆测参考图服装与外貌。
- 保存预演不修改 Scene 正文、提示词、参考图、项目画幅或已有 Blocking。采用时先导出可审阅站位建议，由用户显式采用到现有站位编辑表单，再显式保存；不自动替代。
- 对象稳定 ID、数值范围、对象数量、文档大小与项目归属需校验。保存以版本前置条件防止旧页面覆盖新文档。切 Scene/关闭面板释放 WebGL 与事件资源。
- 本次不做运动路径、相机关键帧、视频导出或新模型生成；PNG 首期仅下载，不自动进入生成链。

## 代价

新增客户端图形依赖和 WebGL 兼容要求；不可用时明确报错，不将 2D 画面冒充真实 3D。文档存储独立于业务权威字段，撤回面板不影响已有媒体与生成任务。
