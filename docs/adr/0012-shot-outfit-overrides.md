# ADR-0012：镜头级造型覆盖进入生成链路（方案 A）

状态：已采纳（用户选择方案 A）。已实现，本地测试见 `backend/internal/service/shot_outfit_overrides_test.go`；尚未做真实生成验收。

## 背景

镜头编辑器的“镜头造型覆盖”写入 `ShotCharacterOutfit`，但代码核对结果显示：该表只被角色历史展示、Scene 合并和 Native 拆分复制读取，**所有图片/视频生成路径都不读它**，保存后对生成没有任何作用。
生成以 Scene 为单位：分镜图是一张首帧，H3 视频一次生成整段，内部用 `[Shot N]` 分段。

## 决定

1. **开场造型 = Shot 1 实际造型。** 角色在 Shot 1 有已审核覆盖时，替代该角色的场景级套装；否则沿用场景级选择。
   `sceneCharacterOutfits` 改为返回开场造型，因此分镜首帧参考图、视频参考图、显式参考列表自动补入、缺图检查、四视图分镜参考、【角色设定】（含年龄阶段）、场景内容扩写全部一致切换，不再各自判断。
2. **后续镜头换装 = 额外参考图 + 提示词换装句。**
   - 逐镜计算每个角色的有效造型（镜头覆盖 > 场景选择 > 角色主形象），与上一镜不同即记为一次换装。
   - 开场未使用、之后换上的套装作为额外参考图，追加在场景/道具之后、当前分镜图之前（自动与显式参考两条路径相同），说明行为“造型套装「X」…（自 Shot N 起换装，开场不使用）”。追加在末尾是为了不改变分镜图与视频共用的既有 `<Picture N>` 编号。
   - 在视频提示词对应 `[Shot N]`（含 `At mm:ss.mmm,`）之后插入固定句式：
     `From this shot on, <角色> wears the outfit 「X」 shown in <Picture k> (same person and face).`；
     换回主形象时为 `... returns to the default look shown in <Picture k> ...`。
     提示词不含 `<Picture` 引用（T2V/I2V/首尾帧模板没有角色参考图）或对应图片因上限未提交时，只写套装名不写编号。
   - 插入点挂在 `applySceneShotTimeline` 末尾，所有生成/预览/提交路径都经过它。每次先删除旧的同句式再按当前数据重写，因此重复调用逐字幂等，造型改动后旧编号不会残留。
3. **只在镜头计划可用时生效。** 导演镜头过期（`DirectorSourceStale`）时不读覆盖；提示词中不同 `[Shot N]` 数量与镜头数不一致（导演合并/增加了切点）时不插入换装句，额外参考图仍附带并标明起始镜头。
4. **只认已审核、属于该角色、该角色在画面中可见的套装。** 未审核覆盖被忽略。
5. **失效语义与场景造型一致。** `AssignShotOutfits` 内容实际变化时：所属 Scene 标记 `prompt_stale`，取消在途图片/视频任务，候选标记过期但保留；已生成媒体不删除、不自动重新生成。内容未变化时不做任何标记。
6. **无覆盖时逐字不变。** 没有任何镜头覆盖的 Scene，参考图列表与提示词与修改前完全相同。

## 不做

- 不保证同一段 H3 视频中途换装成功：这是模型能力边界。需要可靠换装时应把镜头拆为独立 Scene（方案 B 留作人工操作）。
- 镜头中途切换年龄阶段（身份变化）不支持：【角色设定】只描述开场阶段；跨年龄请拆 Scene。
- 镜头级“独立造型资产”（`ShotCharacterLook`）同样未被生成读取，本 ADR 不处理。
- 分镜四视图 `source_hash` 不含造型选择（既有缺口），不在此处修改。
- 不改数据结构，不做真实生成验收。
