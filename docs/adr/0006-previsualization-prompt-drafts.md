# ADR-0006：3D预演直接生成提示词草稿

状态：用户已批准。

延续ADR-0005的独立预演存储，新增直接准备提示词路径：预演空间建议与当前站位表单按同名人物合并，仅更新几何位置和朝向，保留原文事实、视线、关系及起止状态。预览可使用未保存站位，不写Scene或媒体；Scene正文、Shot、对白保持权威，不从静态几何推测动作或外貌。

显式确认采用时原子保存站位与审阅后的提示词，写入对应applied hash，清空另一类旧站位关联。采用必须携带预览输入版本，版本变化返回409且不写入。已确认稿仅在用户明确确认替换后更新。预演文档仍可独立保存、删除和修改，不自动覆盖或作废已采用稿。

保留旧的先保存站位再预览路径。无真实图视频生成，无运动路径或关键帧功能。预演空间文本由同一确定性序列化器生成，不通过模型推断几何。
