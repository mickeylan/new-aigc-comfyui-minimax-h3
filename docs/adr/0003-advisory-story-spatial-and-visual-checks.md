# ADR-0003：空间关系保留；撤回故事来源与分镜图检查

- 状态：部分撤回（用户明确要求删除两项检查）
- 日期：2026-11-06

## 撤回原因

故事来源检查和分镜图检查未经过实际生产流程与真实模型验收，没有解决用户故事被提示词改丢的问题。接口、模拟供应商测试通过不能作为功能实际可用的证据。

## 当前决策

1. 删除故事来源检查、分镜图检查的界面、API、实现及专用测试。
2. 删除关联的检查记录、修正预览/应用、拆合镜检查报告及专用视觉能力设置；不以更多检查入口代替生成链正确性。
3. 保留独立的空间与动作关系：在现有站位数据中区分人物参照、摄影参照、功能端、运动起止，以及原文事实与AI建议。只有显式保存的当前正文关系才进入提示词。
4. `Scene.Content` 仍是故事权威。生成提示词应完整表达当前正文中的可见过程和明确对白，不因精简字数删除因果链，不凭参考图片新增剧情。
5. 不删除正文、镜头、媒体、候选或已有数据库历史。已部署数据库可能保留不再使用的旧报告列，不执行破坏性删列。
6. 后续功能须先确认真实供应商、文件存储及完整操作路径可用，明确区分模拟回归与实际模型验收。
