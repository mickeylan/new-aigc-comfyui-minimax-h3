# ADR-0013：统一角色参考人脸设计

状态：方案已采纳，用户明确同意先记录 ADR 再实施；本地实现，待真实模型和浏览器验收。

实现入口：角色标准像操作区「参考人脸设计」。`CharacterFaceDesign` 与有序的 `CharacterFaceReference` 保存预览/提交记录，通过任务 ID 关联现有标准像历史；界面可查看最近30次设计来源。所有新流程独立于原文字生成入口，结果仍复用同一标准像字段与 `updateSelectedAsset`。

## 目标

在角色标准像入口统一提供「双亲参考」与「多脸融合」两种预设，共用参考输入、提示词审阅、任务提交和历史机制。保留现有文字生成路径，不新增专用模板，不扩展家谱、遗传预测或精确融合比例功能。

## 决定

1. **一个入口、两个预设。** `dual_parent` 要求父亲、母亲两个明确槽位；`multi_face_fusion` 要求至少两张参考脸。预设只定义语义与参考职责，不各自实现上传、校验、Skill 或生成流程。目标年龄、性别来自角色资料和用户要求，不写死幼童或成年。
2. **参考集有序且可追溯。** 上传和本项目已有图片共用参考选择组件。每项记录具体文件版本、内容摘要、来源、顺序和参考职责；不得仅绑定可变的角色当前标准像。复用现有 `validateProjectImageUpload`、`fileSHA256` 与安全路径校验，不重复实现。移除选择不删除源资产。
3. **审阅的是整套设计。** 参考集、职责、目标要求、预设或引擎改变后，已有审阅状态失效；提交时核对设计版本。保存最终提示词、有序参考集、引擎、参数、模板标识及任务关联。独立的角色设计记录保留来源，不新增第二个「当前标准像」字段，不泛化现有 Scene 快照作用域。
4. **通用角色 Skill 负责人物设计。** 复用 `chatWithCharacterDesignSkill` 及现有审计；女性优先美术增强，明确未成年除外。引擎适配只处理图片引用编号、输出格式、画幅及参数。未分析图片时不臆测参考人物的具体五官。人工可以修改参考重点和最终提示词。
5. **复用同一套多图编辑模板。** Qwen 使用 `qwen_image_2_1_multi_edit` 与 `<imageN>`，标准像打开画幅开关，输出 9:16。H3 使用 `minimax_h3_image_edit` 与 `<Picture N>`，指定标准像宽高；不复制模板。引擎能力由服务端集中提供，前端消费；超限拒绝，不静默截断。
6. **H3 不是最多三张。** 2026-11-20 核查 ComfyUI 上游 `comfy_extras/nodes_minimax_h3.py`，`MiniMaxH3ImageConditioning.define_schema` 定义 `images` 为 AUTOGROW，`prefix="image_", min=0, max=100`。当前仓库模板只接三张是配置限制，需同时扩展图片加载节点与接线，不能仅改 `max_count`。上游节点结构上限不等于目标实例版本兼容性、显存容量或多脸融合质量保证；这些仍需验收。
7. **标准像只有一个生效口径。** 生成成功复用 `updateSelectedAsset`，带任务 ID 守卫，保留旧图为 `AssetVariant`。旧任务不能覆盖新的设计或手工选择。成功结果与设计记录关联，历史可追溯、可恢复。已有批量文字生成行为不改，不悄悄改成付费参考生成。
8. **参考文件也是受保护的项目资产。** 删除和清理路径须检查设计记录引用，不能删除仍被设计使用的源图片。按具体文件绑定避免来源角色换图或合并后参考含义改变；来源不可读或内容变化时明确报错，不自动换图。
9. **定脸后沿用自身标准像。** 后续四视图、换装、年龄阶段使用新角色自己的标准像，不每次重新融合父母或参考人物。采用/恢复标准像沿用既有失效机制，保留已生成派生资产，不自动重生成。

## 验收

- 两个预设走相同的参考解析、权限校验、审阅与任务路径。
- 覆盖图片排序与职责、固定文件版本、跨项目拒绝、超限拒绝、修改后重新审阅、任务防覆盖和历史恢复。
- H3 多图渲染覆盖一张、超过十张与边界数量；未提供图片不得残留悬空接线。Qwen 与旧文字生成保持回归通过。
- 执行 `go -C backend build ./...`、`go -C backend test ./... -count=1`、`npm --prefix frontend test`、`npm --prefix frontend run build`。
- 本次开发不真实生成、不部署、不改超时或重试策略；真实人脸融合自然度、差异化与目标 ComfyUI 节点兼容性另行人工验收。艺术化子女设计不代表遗传预测。
