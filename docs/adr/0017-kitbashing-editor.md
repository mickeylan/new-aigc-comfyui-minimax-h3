# ADR-0017：Kitbashing 编辑与存档契约

状态：已采纳，分阶段实施中。用户确认按推荐分阶段补齐，并采用推荐默认。

## 决定

1. 场景写v6、读v1–v6。对象（含平面/泼溅）具有稳定ID、visible/locked；隐藏对象仍完整存档，但不参与取景、表面拾取和路径避障。锁定阻止变换、删除和摆姿。旧档默认可见且未锁定。

   > 更正（2026-11-24）：本条原写「写v5、读v1–v5」。核对代码后确认实际写v6、读v1–v6，且v6要求存档内每个对象都带稳定ID（`frontend/src/studio/scene3d/Scene3DStage.tsx:2859`写入、`:3008`读取、`:3035`校验ID全覆盖）。稳定ID迁移最初在ADR-0016落地，v5→v6的差别就是这项强制校验。此处按代码实况更正，不改变任何既有契约。
2. 对象编辑历史只在当前会话；删除资源延迟到历史不再引用后释放，载入清空历史。复制骨架使用SkeletonUtils；媒体副本独立管理资源，不复制临时句柄。历史不写存档。
3. 吸附/world-local为编辑偏好；最终全轴TRS写存档。拖放先命中可见内容表面，排除辅助物/泼溅，未命中回退地面。
4. 复用素材接口做服务端搜索/分类，不能仅筛已加载的一页；基础形状为前端静态几何目录，不伪造素材行。
5. 画幅属于场景，垂直FOV为投影权威，毫米焦距仅换算；视口与所有输出共用画幅。画幅变化必须使生成快照审阅失效。
6. 在途加载有场景代次保护，迟到结果释放；存档保持不可变另存为，支持名称/预览/恢复提示，不新增覆盖接口。保存期间修订变化不能误报已保存。

## 阶段

- 一：对象管理、编辑历史、变换、表面落点与v5往返。
- 二：服务端资产检索/分类、基础形状与加载保护。
- 三：画幅/焦距统一取景、存档命名/预览与恢复体验。

保留ADR-0015自包含媒体、32MiB上限、骨姿与辅助物隔离；保留ADR-0016人工审阅和候选采纳。不合并其他预演文档，不新增对象动画/资产商城/物理系统，不提交推送、不部署、不真实生成、不触碰18000。

### 本轮剩余项目验收与修复

- BROWSER_REMAINING_QA=PASS：浏览器MediaRecorder生成真实WebM；视频副本HTMLVideoElement/VideoTexture独立，暂停原件不影响显式播放的副本，复制/删除/撤销/存档恢复通过，替换场景后旧解码器src已释放。自动播放受浏览器策略限制，允许保留首帧。
- 使用Spark PackedSplats/writeSpz生成真实SPZ并由生产加载器解码；副本拥有独立PackedSplats，原始字节逐字节入档/恢复。增加非默认内层位置/尺度验收后发现复制会丢失归一化TRS，现复制内层TRS、v5新增可选contentTransform写入/恢复并校验有限向量；旧档缺省保持原读取路径。不是通过共享句柄假装复制。
- 真实DOM拖放事件命中抬高模型表面，放置高度保留；生产TransformControls指针运算验证世界/局部坐标平移、0.1吸附及关闭吸附。BROWSER_CONTROLS_QA=PASS额外验证世界/局部旋转15°与缩放0.1共四组合。
- BROWSER_RACES_QA=PASS：延迟PNG编码期间切换场景，旧序列停止且不下载混合ZIP；首尾帧在编码返回后不再上传；单参考图迟到不附着新场景；旧相机播放停止，新相机/FOV/画幅不回滚；在途库OBJ与模拟生成任务返回后不放进新场景。模拟任务只截获本地fetch，未调用真实生成。
- PNG编码改为返回promise、不在临时状态中await，finally同步还原材质/辅助物/机位。载入同步取消移动/相机rAF及兜底定时器、清旧参考图与序列缓存。单图/首尾帧/序列均加入操作身份及代次校验，序列在异步边界复核。

### 保存脏标记轮询优化（本轮实现，未提交）

- 3D 场景每 500ms 的脏检查原先每次都把整份场景状态（含内嵌媒体 data URL）JSON 序列化后再比较。现改为两级指纹：`buildSceneFingerprint` 一次遍历产出 `structure`（媒体载荷替换为其长度）和 `media`（逐项源字符串），轮询只比结构字符串与媒体逐项值；保存、离开、载入、导入等安全闸门仍用 `full()` 的完整序列化，闸门语义不变。
- 媒体源只在平面创建时写入一次、没有原地 setter，这是「同长度换内容也算修改」能便宜判定的前提；新增回归专门覆盖同长度、同前缀、仅末字符不同的载荷。
- `SceneSaveGuard` 保留原字符串 API（`markSaved('x')` 仍有效），新增 `isDirtyState` 供轮询使用，现有调用与断言未改。
- 回归：2MB 媒体载荷下轮询只发生一次 `JSON.stringify`，structure 长度小于 400 字符；只有 `full()` 才序列化正文，同一快照内重复读取复用缓存；指纹不修改传入行；`markSaved` 复制媒体数组，调用方后续扩容不能污染基线。`npm --prefix frontend test` 退出 0：Node 657/657、Vitest 136/136（20 文件）；生产构建退出 0（22.05 秒，既有大包警告）。本轮未提交、未推送。
