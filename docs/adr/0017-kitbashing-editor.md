# ADR-0017：Kitbashing 编辑与存档契约

状态：已采纳，分阶段实施中。用户确认按推荐分阶段补齐，并采用推荐默认。

## 决定

1. 场景写v5、读v1–v5。对象（含平面/泼溅）具有稳定ID、visible/locked；隐藏对象仍完整存档，但不参与取景、表面拾取和路径避障。锁定阻止变换、删除和摆姿。旧档默认可见且未锁定。
2. 对象编辑历史只在当前会话；删除资源延迟到历史不再引用后释放，载入清空历史。复制骨架使用SkeletonUtils；媒体副本独立管理资源，不复制临时句柄。历史不写存档。
3. 吸附/world-local为编辑偏好；最终全轴TRS写存档。拖放先命中可见内容表面，排除辅助物/泼溅，未命中回退地面。
4. 复用素材接口做服务端搜索/分类，不能仅筛已加载的一页；基础形状为前端静态几何目录，不伪造素材行。
5. 画幅属于场景，垂直FOV为投影权威，毫米焦距仅换算；视口与所有输出共用画幅。画幅变化必须使生成快照审阅失效。
6. 在途加载有场景代次保护，迟到结果释放；存档保持不可变另存为，支持名称/预览/恢复提示，不新增覆盖接口。保存期间修订变化不能误报已保存。

## 阶段

- 一：对象管理、编辑历史、变换、表面落点与v5往返。
- 二：服务端资产检索/分类、基础形状与加载保护。
- 三：画幅/焦距统一取景、存档命名/预览与恢复体验。

保留ADR-0015自包含媒体、32MiB上限、骨姿与辅助物隔离；保留ADR-0016人工审阅和候选采纳。不合并其他预演文档，不新增对象动画/资产商城/物理系统，不提交推送、不部署、不真实生成、不触碰18000。

## 验证

各文件修改后单独验证；完整前端test/build、后端涉及的查询测试、v5隐藏对象/锁定往返、历史资源生命周期以及隔离浏览器行为验收。实施和验收结果逐阶段补充，不将计划视作完成。

### 当前落地与验证

- 已接线对象复制（网格独立几何/材质/纹理、媒体重新解码）、会话历史、删除延迟释放、显隐/锁定/聚焦、全轴数值变换、world/local与固定吸附、表面优先落点、基础形状。
- v5保存稳定ID/显隐/锁定，GLB存档onlyVisible=false；移动计划存targetId，旧档名字回退。读v1–v4不变。
- 服务端q按名称字面子串检索、先过滤后分页；category仅model(GLB/GLTF/OBJ)与splat(SPZ/SPLAT/KSPLAT)，不伪称上游语义资产标签。前端250ms查询防抖及旧响应隔离。
- 已加入主要文件/库/平面/天空盒/存档载入的sceneEpoch保护；场景画幅letterbox和FOV→毫米焦距换算；新存档记录画幅与名称，机位出图快照包含frame，改画幅/焦距关闭旧审阅面板。
- 保存加入修订一致性校验、dirty状态及未保存离开/载入提示；上传期间继续编辑不会误清dirty。新存档内嵌JPEG缩略图，后端存档先预览再显式恢复，取消不替换场景；保存后自动刷新列表。
- 已引入按操作身份管理的忙态集合，竞争存档载入只允许最新请求提交，较旧请求结束不能清除其他请求忙态。主要生成任务返回后检查场景代次，不将旧场景结果放回新场景。
- 浏览器验收修复两处实际缺陷：本地保存变量遮蔽DOM document；图片平面的GPU材质version变化误判用户编辑，现按材质实际属性比较并新增回归测试。序列指定宽度改按物理像素输出并finally恢复屏幕DPI，修复720宽在1.25倍DPI变成900宽。
- 最新完整回归：637个Node用例、96个Vitest用例（15个测试文件）通过，npm --prefix frontend test与生产构建exit0；go -C backend test ./... -count=1 exit0。
- 5180隔离浏览器通过：基础形状、复制/撤销/重做、隐藏几何真实GLB存档往返、锁定数值变换阻止、画幅往返、服务端搜索参数接线；dirty添加→保存后clean、保存中修改拒绝混合快照、上传竞态保留dirty、恢复预览取消及确认恢复。
- 追加矩阵通过：竞争存档载入、图片平面复制/删除/撤销/自包含存档往返；9:16与1:1下截图、白模/法线/深度单图、首尾帧，以及三种pass序列ZIP内每帧像素尺寸（720×1280/720×720）。首尾帧上传走本地夹具，未写真实素材库。所有验收夹具均已移出产品目录。

- 部分旧操作仍使用单值忙态，尚未全部迁入操作集合；导出中途编辑/切换场景的一致性保护尚未全面收口。
- 生成任务跨场景返回保护已接线，但尚未完成浏览器行为验收；运动播放/导出已用canMoveEntry排除锁定/隐藏对象，动态切换与跨场景时序仍需完整验收。
- 视频/泼溅复制的真实解码往返、竞争库资产载入、真实表面拖放、世界/局部吸附仍待补验。图片平面与竞争存档已通过，不等同于全部媒体/资产类型均通过。
